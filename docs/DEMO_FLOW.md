# Demo Flow Placeholder

## Planned Buildathon Demo Steps:
1. **Agency staff login**: Operator accesses the agency branch portal.
2. **Register parcel**: Operator registers a package traveling from Douala to Bamenda.
3. **Generate tracking ID**: System creates a unique tracking code.
4. **Track parcel**: Customer checks parcel status using the tracking code.
5. **Update status**: Operator updates parcel status to 'In Transit'.
6. **Demonstrate arrival notification**: Status is updated to 'Arrived' at Bamenda, showing arrival notification.
